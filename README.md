🚀 Dynamic Memory Management Visualizer

A comprehensive simulation tool to visualize Paging, Segmentation, and Virtual Memory techniques used in modern operating systems. This project helps students, developers, and OS enthusiasts understand memory handling through interactive, step-by-step visualization.

📌 Features
🔹 Memory Management Techniques

Paging Simulation

Page tables

Frame allocation

Page faults tracking

Segmentation

Custom segment allocation

Logical-to-physical mapping

Virtual Memory

Swapping in/out pages

Fault detection and handling

🔹 Page Replacement Algorithms

FIFO (First-In-First-Out)

LRU (Least Recently Used)

OPT (Optimal Algorithm) (optional upgrade)

Each algorithm includes:

Frame-by-frame visualization

Victim page detection

HIT/FAULT status updates

🔹 Interactive User Inputs

Users can customize:

Number of frames

Reference string

Algorithm selection

Segment sizes

Allocation requests

🔹 Performance Metrics

Total memory references

Page hits and faults

Hit ratio

Fault percentage
